Nova pour ordinateur

Tes chaînes, films et séries Nova sur ton Mac ou ton PC, avec la même interface que sur la télé.

Télécharger pour Mac macOS 11 ou plus récent · environ 250 Mo Télécharger pour Windows Windows 10 ou 11 · environ 130 Mo

Tu lis cette page sur ton téléphone ? Ouvre-la plutôt sur l’ordinateur où tu veux installer Nova.

Installer sur Mac

  1. Clique sur Télécharger pour Mac.
  2. Ouvre le fichier Nova-Mac.dmg (dans Téléchargements).
  3. Dans la fenêtre qui s’ouvre, fais glisser l’icône Nova sur le dossier Applications.
  4. Ouvre Nova depuis le Launchpad ou le dossier Applications. Si le Mac demande s’il faut l’ouvrir, clique sur Ouvrir.

Installer sur Windows

  1. Clique sur Télécharger pour Windows. Si le navigateur dit que le fichier n’est pas souvent téléchargé, choisis Conserver.
  2. Ouvre le fichier Nova-Windows.exe.
  3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. C’est normal pour une nouvelle application, et ça n’arrive qu’une fois.
  4. Nova s’installe toute seule et s’ouvre. Ensuite, tu la retrouves sur le bureau et dans le menu Démarrer.

Se connecter

  1. Au premier lancement, Nova te demande ton compte.
  2. Le plus simple : colle le lien que tu as reçu avec ton abonnement dans URL M3U (connexion automatique). Sinon, remplis Serveur, Identifiant et Mot de passe.
  3. Donne un nom au compte (par exemple « Maison »), puis clique sur Enregistrer et connecter.

Nova retient ton compte : tu n’auras plus à le taper.

Utiliser Nova

  • Souris ou trackpad : fais défiler les listes et clique sur une chaîne, un film ou une série.
  • Clavier : les flèches et Entrée marchent comme la télécommande, Échap revient en arrière.
  • Espace : pause et lecture.
  • Direct en plein écran : amène la souris sur le bord gauche pour voir la liste des chaînes.
  • Double-clic sur l’image : sortir du plein écran.
